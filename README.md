Entry for the make.fun bounty [Two Lines of Morning Light](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5).

`main.py` writes one two-line micro poem about light and morning to `/output/entry.txt` (95 characters, inside the 1–120 gate):

> Morning light slides under the door, an unsigned note,
> and waits on the rug for you to read it.
